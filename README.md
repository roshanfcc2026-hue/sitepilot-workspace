# Sitepilot — Personal website & outreach workspace

Website reviews, contacts, conversations, replies, follow-ups, campaign drafts, and SEO content briefs in one private workspace.

## Open Sitepilot

[Open the live Sitepilot website](https://sitepilot-audit-studio.roshanfcc2026.chatgpt.site/).

The website is public to view. Sign in with ChatGPT to save and use your own workspace. Saved contacts, notes, and outreach records remain private to the signed-in account.

## Download the complete source

[Download sitepilot-source.zip](./sitepilot-source.zip) (open the file, then choose **Download raw file**). Extract it into an empty folder and follow the included README to install dependencies, initialize the local database, and run the app.

The source package contains 147 files from the tested application, including its React interfaces, server routes, database migrations, and tests. This copy starts with an empty workspace. It excludes the original owner's research, contact records, database, deployment identity, and credentials.

## What you can track

- Websites analyzed and worked on.
- Unique people contacted, replies, total messages, and reply rate.
- People linked to each website, contact details, private notes, and client stages.
- Due and overdue follow-ups, next steps, and a recoverable conversation timeline.
- Website findings, copyable feedback, campaign drafts, and SEO briefs.

Messages and replies are logged manually. No email is sent and no inbox is connected. The repository is source code, not a hosted application; GitHub Pages cannot run its server routes or database. The live application runs on Sites; saved workspace data requires authentication.

## Sharing

This repository is public. Anyone with the link can view and download the source package, and the live website link above is public to open. The owner's saved workspace records remain private.
